# 🌦️ Weather Forecasting System
Developed a Weather Forecasting System using Python, Flask, HTML, CSS, and JavaScript. It provides real-time weather updates, 5-day forecasts, and AI-based temperature predictions using Machine Learning. Integrated the Open Weather API and SQLite database for weather data and search history management.
# Technologies Used:
- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: SQLite
- API: OpenWeather API
- Machine Learning: Scikit-learn

# Key Features:
1. Real-time weather updates for any city.
2. Five-day weather forecast.
3. AI-based temperature prediction.
4. Weather search history.
5. Delete individual or clear all history records.
6. Responsive and interactive dashboard.
7. Weather Forecast/
